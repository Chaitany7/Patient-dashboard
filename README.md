
# Patient Dashboard

A patient diagnosis dashboard built using React.js.
View live website: https://chaitany7.github.io/Patient-dashboard/

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Chart.js
- React Chart.js 2

## Features

- Patient listing
- Patient profile
- Diagnosis history
- Diagnostic information
- Lab results
- Graphical visualization of patient health data

## Installation

Clone the repository:

```bash
git clone https://github.com/Chaitany7/Patient-dashboard.git
```

Navigate to the project directory:

```bash
cd Patient-dashboard
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open http://localhost:3000 in your browser.
